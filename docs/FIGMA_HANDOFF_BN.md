# FarmSphere — Figma design handoff

এই package-এ Figma.com-এর native .fig ফাইল বা cloud project **তৈরি করা হয়নি**। Tool connection পাওয়া যায়নি। তবে `FIGMA_DESIGN_SYSTEM.json`-এ tokens আছে এবং `EnterpriseERP.Web/wwwroot/css/site.css`-এ implementation পাওয়া যাবে।

Figma-তে: 1440×900 desktop frame এবং 390×844 mobile frame তৈরি করুন। Pine #173D35, canvas #F5F7F4, mint #E8F3EB, accent #BCE279 ব্যবহার করুন। Components: sidebar (252px), topbar (78px), cards (16px radius), hero, KPI, tables, form and status states. Browser preview `design-preview/index.html` খুলে layout অনুসরণ করুন।

**Security:** company/branch switch is authorized server-side; UI visibility is not authorization.
